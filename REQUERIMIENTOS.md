# Requerimientos del Proyecto

## Objetivo del sitio

Landing Page para promocionar recursos dirigidos a emprendedores, permitiendo conocer información, beneficios y facilitar el contacto mediante un formulario.

---

## Secciones del sitio

- Inicio (Hero)
- Recursos
- Beneficios
- Testimonios
- Formulario de contacto
- Pie de página

---

## Requerimientos funcionales

- Mostrar información de los recursos.
- Mostrar testimonios dinámicamente.
- Validar el formulario de contacto.
- Manejar datos mediante Programación Orientada a Objetos.
- Permitir la navegación mediante el menú.

---

## Requerimientos no funcionales

- Diseño responsivo.
- Compatible con dispositivos móviles.
- Uso de animaciones CSS.
- Código organizado.
- Uso de Git y GitHub para el control de versiones.
