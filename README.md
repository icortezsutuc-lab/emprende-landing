# Emprende - Recursos para Emprendedores

## Descripción

Este proyecto consiste en una Landing Page desarrollada con TypeScript, Vite, SCSS y Programación Orientada a Objetos (POO). La aplicación permite mostrar recursos para emprendedores obtenidos desde un archivo JSON y cargados dinámicamente en la página.

## Tecnologías utilizadas

- HTML5
- SCSS
- TypeScript
- Vite
- Git
- GitHub
- JSON
- Fetch API

## Estructura del proyecto

```
src
│
├── controllers
│   └── RecursoController.ts
│
├── interfaces
│   └── IRecurso.ts
│
├── models
│   ├── Recurso.ts
│   └── RecursoPremium.ts
│
├── services
│   └── RecursoService.ts
│
├── main.ts
│
public
│
└── recursos.json
```

## Funcionalidades

- Landing Page responsiva.
- Carga dinámica de recursos desde JSON.
- Programación Orientada a Objetos.
- Uso de Interfaces.
- Uso de Herencia.
- Controlador para administrar los recursos.
- Diseño desarrollado con SCSS.
- Gestión del proyecto mediante Git y GitHub.

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/icortezsutuc-lab/emprende-landing.git
```

Entrar a la carpeta del proyecto:

```bash
cd emprende-landing
```

Instalar dependencias:

```bash
npm install
```

Ejecutar el proyecto:

```bash
npm run dev
```
